# AI-Powered IT Support & Incident Resolution Assistant

Production-style AI Application designed to assist IT support teams with incident analysis, classification, priority prediction, semantic knowledge retrieval (RAG), and grounded troubleshooting step generation.

## 🏗️ Project Architecture
- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic
- **Frontend:** Streamlit
- **ML / NLP:** Scikit-Learn, TF-IDF
- **LLM / RAG:** Gemini API + Semantic Vector Search
- **Database:** PostgreSQL
